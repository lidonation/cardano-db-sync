# Cardano DB Sync

Start with the [installation guide](./guides/installation.md), or browse the guides in the sidebar.

`cardano-db-sync` follows the Cardano chain and writes it into a Postgres database you can query
with ordinary SQL. Operational documentation lives in the guides; reference descriptions are extracted from
Haskell annotations. Historical documentation remains available at the corresponding git release tags.
