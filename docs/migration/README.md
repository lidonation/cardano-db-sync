# Staged legacy guides

published as site pages yet. Adding all of them to the current Docusaurus build exceeds the
existing JavaScript budget. Do not remove the canonical `doc/` sources or treat staging as the
completion of migration: publish these guides after a measured solution meets the existing budget,
then complete parity and guide-lock review. The build's guide validation also checks this directory.
